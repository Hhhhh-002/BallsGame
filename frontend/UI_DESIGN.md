# 球球客户端视觉改造

明亮的冰蓝控制台围绕深蓝轨道战场，彩色凝胶球是视觉焦点。保留 TypeScript、Vite、Canvas 2D，不引入新渲染引擎或远程字体。

配色：冰蓝 #eef5ff、深海蓝 #132c51、操作蓝 #3478ed、我的球薄荷绿 #58dfc1、能量金 #ffc76d、文字墨蓝 #182f50。标题使用 Bahnschrift / 中文系统字体，正文使用 Segoe UI / Microsoft YaHei UI；计数使用等宽数字。

桌面：顶部品牌与连接状态、简短标题、主战场与右侧排名和操作说明。手机：战场优先，侧栏下移，操作区域至少 44px。HUD 和小地图不拦截输入。保留所有 DOM ID、表单字段、校验和事件绑定。

| 屏幕 | 主要操作 | 状态 |
| --- | --- | --- |
| 登录 / 注册 | 填写邮箱密码、切换注册 | 保留确认密码、请求禁用、错误；背景注明示意 |
| 大厅 | 本局昵称、开始比赛 | 等待、原请求重试、取消清理 |
| 对局 | 移动、分裂、吐球、离场 | 暗网格、薄荷球与“我”文字，状态取自服务端 |
| 观战 | 跟随对象、离场后再开 | 原有观战和离场确认流程 |
| 结算 | 完整排名、再开、返回 | 真实名次、面积、人数，长榜滚动 |
| 设置 / 日志 | 网关地址、连接日志 | 保留配置优先级及连接行为 |

只修改 layout、CSS、Renderer。网关、协议、Input、World、Handler、main 的业务逻辑不变。保持原有镜头跟随和方向坐标换算；粒子不产生碰撞、位移或计分，不添加客户端位置预测和镜头震动。

凝胶球和食物纹理预绘制复用，屏幕外对象跳过绘制，网格仅覆盖可见区域。食物超过 2000 颗且屏幕半径小于 4px 时按颜色批量画圆，显示半径仍为 0.45；较大显示尺寸保留凝胶柔光。appear 表现新球/分裂、增长和合并的扩散环；vanish 表现已确认消失的收束环；food 表现吞食碎光。新增食物闪光仅读取服务端集合，不猜测吐球方向或归属。限制特效数量和持续时间，尊重减少动态效果设置。

验证：类型与构建、现有离线回归、桌面/手机浏览器流程、减少动态效果、昵称安全、渲染与 World 隔离；检查登录、注册、战场、观战和结算截图。
