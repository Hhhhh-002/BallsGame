## 项目说明

本项目是本人在学习过程中从零独立开发的多人实时在线游戏，主要聚焦 Java 游戏服务端架构与核心游戏逻辑的设计和实现。Web 客户端在 AI 辅助下开发，用于联调与玩法展示。项目仍有不少不足，后续将持续完善功能、优化性能，并改进工程质量。欢迎交流与指正。
